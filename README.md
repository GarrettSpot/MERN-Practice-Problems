# MERN Practice Questions

To practice these questions, simply run these commands.

For example, to test your 1-Lok_Sabha answer:

Linux/MacOS/WSL:
```bash
cd "1-Lok_Sabha"
npm install
npm test
```

Windows Powershell:
```powershell
Set-Location ".\1-Lok_Sabha"
npm install
npm test
```

Simply change the folder's name to target question.
